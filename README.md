##  Introduction

This is a responsive multi-page website inspired by BMW's branding, showcasing their most iconic models and providing a sleek, modern user experience. Built using HTML and CSS, it includes a home page, models listing, and contact sections, all optimized for both desktop and mobile viewing.

---

##  User Experience (UX)

###  User Stories

- **As a car enthusiast**, I want to browse different BMW models, so I can choose the one that suits my needs.
- **As a prospective customer**, I want a clean layout and intuitive navigation, so I can easily find the information I need.
- **As a mobile user**, I want a responsive design, so the website works well on my phone.

---

##  Design Choices

- **Colors:** White text on a black header background to reflect BMW’s premium, sleek identity.
- **Typography:** Roboto and Arial fonts are used for clarity and modern appeal.
- **Layout:** Grid layout for model showcase; flexbox used in headers for alignment.
- **Imagery:** Images from BMW's official website and placeholders stored in the `images` or `assets` folders.
- **Wireframes:** Designed in Figma (add screenshots if applicable).
